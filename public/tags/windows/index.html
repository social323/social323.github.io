CVE-2024-44193: iTunes AppleMobileDeviceService Arbitrary File Deletion to SYSTEM

Overview CVE-2024-44193 is a local privilege escalation in iTunes 12.13.2.3, patched September 12, 2024. Two weaknesses combine: C:\ProgramData\Apple\Lockdown\ is writable by unprivileged users AppleMobileDeviceService.exe (SYSTEM) recursively deletes unexpected files from that directory on service start Planting an NTFS junction redirects the deletion to an arbitrary path. Chained with MSI rollback, this places a malicious DLL and achieves SYSTEM code execution. CVE-2021-21551: Dell dbutil_2_3.sys Arbitrary Kernel Memory R/W (BYOVD)

Overview CVE-2021-21551 resides in Dell’s signed kernel driver dbutil_2_3.sys. The IOCTL dispatch routine performs no validation on user-supplied buffers, exposing arbitrary physical and kernel memory R/W to any local user. Since the driver is validly signed, it loads on systems with DSE enabled — a classic BYOVD attack. CVE-2023-36424: Windows clfs.sys Kernel Pool Overflow LPE

Overview CVE-2023-36424 is a kernel pool overflow in clfs.sys, the Windows cloud file mini filter driver. The driver validates only the first 10 records from a crafted NTFS reparse point, allowing overflow of a fixed 0x4000-byte kernel pool allocation. Successful exploitation yields SYSTEM privileges.
