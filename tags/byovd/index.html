CVE-2021-21551: Dell dbutil_2_3.sys Arbitrary Kernel Memory R/W (BYOVD)

Overview CVE-2021-21551 resides in Dell’s signed kernel driver dbutil_2_3.sys. The IOCTL dispatch routine performs no validation on user-supplied buffers, exposing arbitrary physical and kernel memory R/W to any local user. Since the driver is validly signed, it loads on systems with DSE enabled — a classic BYOVD attack.
